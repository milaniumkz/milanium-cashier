MBusiness.

Каналы общения и CRM

Для компании

  1. Войдите как владелец MBusiness и откройте «Интеграция → Каналы общения».
  2. WhatsApp: нажмите «Войти через Facebook», выберите свой бизнес-портфель, WhatsApp Business Account и номер. Подтвердите номер по инструкции Meta и предоставьте доступ MBusiness. Для нового номера Cloud API после входа раскройте «Регистрация нового Cloud API номера», установите и сохраните PIN двухэтапной проверки. Для Coexistence этот шаг не используется. Добавьте способ оплаты Meta в WhatsApp Manager; без него онбординг и исходящие сообщения могут быть недоступны. Условия переноса существующего номера или Coexistence показывает Meta — не удаляйте действующий WhatsApp до проверки поддержки.
  3. Instagram: нужен профессиональный аккаунт Business или Creator. Нажмите «Войти через Instagram», выберите свой аккаунт и разрешите доступ к сообщениям.
  4. Telegram: создайте бота в официальном @BotFather, скопируйте bot token в защищённую форму MBusiness. Это подключение бота, а не личной переписки аккаунта. Если у бота уже есть другой сервис, MBusiness заменит его webhook; один бот не может одновременно использовать два webhook.
  5. Попросите клиента написать на подключённый канал. Диалог появится в «Сообщения», а клиент и новая сделка — в CRM.
  6. Добавьте сотрудника с ролью «Менеджер продаж» и назначайте сделки/задачи. Закрытие сделки не подтверждает банковский платёж.

Пароли соцсетей не вводятся в MBusiness. Токены хранятся зашифрованными и не показываются повторно. «Отключить» прекращает обработку в MBusiness; для полного отзыва доступа удалите приложение в настройках самой соцсети. Telegram-токен можно перевыпустить в @BotFather.

Ограничения сообщений

WhatsApp и Instagram: свободный текст отправляется только после обращения клиента, в консервативном окне 24 часа. Вне окна для WhatsApp нужны согласие и одобренные Meta шаблоны; отправка шаблонов из MBusiness пока не реализована. Нельзя импортировать список номеров и запускать нежелательные сообщения.

Команды «стоп», «stop», «отписаться», «не пишите» останавливают отправку в диалоге. При неизвестном результате отправка не повторяется автоматически: проверьте исходное приложение перед ручными действиями. Вложения пока отображаются как уведомление: открыть их можно в исходном приложении.

TikTok Direct Messages требует отдельного доступа Business Messaging API. Реклама TikTok не даёт доступа к диалогам. Пока этот доступ не получен, канал обозначен недоступным.

Для оператора MBusiness: однократная настройка

  1. Зарегистрируйте бизнес-приложение MBusiness в Meta for Developers. Подготовьте проверку бизнеса, политику конфиденциальности, удаление данных, домен приложения и рабочие контакты поддержки. Переведите приложение в Live и пройдите App Review/Advanced Access для подключения сторонних компаний. В режиме разработки доступны только тестовые/разрешённые роли.
  2. Настройте WhatsApp Embedded Signup v4 (Facebook Login for Business). Версии v2/v3 прекращают поддержку с 15 октября 2026; MBusiness использует текущий v4 без sessionInfoVersion:3. Для обслуживания сторонних компаний требуется статус Tech Provider/Tech Partner либо Solution Partner согласно правилам Meta. Требуются разрешения whatsapp_business_management, whatsapp_business_messaging и необходимые business_management согласно выбранному сценарию Meta. Включите разрешённый домен JavaScript SDK и создайте Configuration ID с WhatsApp Embedded Signup.
  3. На защищённой странице оператора сохраните Facebook App ID, App Secret, поддерживаемую Graph API version и Configuration ID. По умолчанию v26.0 — версия в актуальных примерах Meta на момент реализации; оператор проверяет поддержку своей версии в Dashboard.
  4. В WhatsApp Webhooks внесите показанные Callback URL и Verify Token, подпишитесь на messages. Подписка каждой WABA выполняется при подключении компании; подпишитесь также на account_update для контроля онбординга; общую настройку приложения нужно сделать заранее.
  5. Для Instagram включите API with Instagram Login, разрешения instagram_business_basic и instagram_business_manage_messages. Введите Instagram App ID и Instagram App Secret (они могут отличаться от Facebook App ID/Secret). Внесите точный OAuth Redirect URI, callback и verify token со страницы оператора; включите messages, messaging_postbacks, messaging_seen.
  6. Используйте HTTPS с доверенным сертификатом и доступным callback. Если площадка отклоняет текущий адрес с портом 8443, потребуется отдельный адрес на стандартном HTTPS-порту 443; это не обходится программной формой. Не меняйте действующий MTaxi для этого.
  7. Выполните боевой тест отдельной компанией: вход, выбор своего номера, входящее сообщение, ответ и статус доставки. Без этого статус программных тестов не считается проверкой реального Meta-аккаунта.

AI и оплата

Откройте «Интеграция → AI-продавец», выберите каналы, заполните правила компании, склад и лимит, сохраните настройки. AI-продавец не включается автоматически при подключении канала. Нужны центральный AI-ключ оператора, настроенные правила продаж, фактические товары/цены и средства на балансе услуг. Предложение рассчитывается по реальным данным склада; клиент подтверждает его фразой «Подтверждаю заказ». Передача заказа на выдачу, фискализация и доставка выполняются сотрудником. Ручной ответ сотрудника приостанавливает AI в диалоге. AI-SMM и рекламные кампании Meta/TikTok пока не подключены. Рекламный бюджет Meta/TikTok клиент оплачивает напрямую площадкам; AI и объявленные услуги платформы оплачиваются отдельно в MBusiness.

Публикации VK и Одноклассники

  1. Откройте «Интеграция → Публикации и рассылки». Владелец входит в соцсеть через её страницу авторизации. Пароль в MBusiness не вводится.
  2. Обновите группы. Доступны только группы с подтверждёнными правами на публикацию; обычное участие в группе права публикации от имени группы не даёт.
  3. Загрузите изображение JPEG/PNG/WebP до 3 МБ, выберите группы, добавьте текст и расписание. Время первой публикации — по часовому поясу устройства; дополнительные даты вводятся с явным смещением, например 2026-11-20T10:00:00+05:00.
  4. Подтвердите права на материалы. Не менее 6 часов между постами, до 3 за скользящие 24 часа, одинаковый материал — не чаще раза в 7 дней. До 300 ожидающих публикаций на компанию.
  5. Следите за статусом, отменяйте лишние ожидающие задания. При неизвестном результате публикация повторно не отправляется и дальнейшие задания группы остановлены до сверки оператором.

Это публикации в управляемых группах, а не личная рассылка всем участникам. Не публикуйте одинаковые навязчивые объявления, не обходите ограничения и соблюдайте правила площадки и закон о рекламе.

Оператору один раз нужны внешние приложения VK/OK и разрешения групп/стены/фото. В OK нужны GROUP_CONTENT и PHOTO_CONTENT; в VK — разрешённый серверный OAuth и wall/photos/groups. Если площадка не одобрила доступ, форма не заменяет разрешение. Эти подключения ещё требуют проверки с реальными аккаунтами.
