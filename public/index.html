Подключение приложения

Создать счёт

Запрос выполняет сервер приложения. API-ключ нельзя помещать в мобильное приложение.

POST /v1/invoices
Authorization: Bearer <ключ компании>
Idempotency-Key: order-1001-attempt-1
Content-Type: application/json

{
  "order_id": "1001",
  "amount": 15000,
  "currency": "KZT",
  "method": "phone",
  "customer_phone": "+77001234567",
  "description": "Оплата заказа №1001"
}

QR и страница оплаты

Для QR укажите method: "qr". Сервис вернёт checkout_url. После создания операции будет доступна платёжная ссылка, если её предоставляет коннектор.

Проверить результат

GET /v1/invoices/:id
Authorization: Bearer <ключ компании>

Заказ подтверждается только после статуса paid. Webhook содержит подпись HMAC SHA-256; проверяйте её, время события, компанию, заказ, сумму и валюту. Повторные события обрабатывайте по event_id.

Режим Android-кассира

Нужно настроить проверенные селекторы установленного Android-приложения, затем подключить сессию командой из карточки компании. В архиве есть инструкция docs/CONNECTOR.md.
