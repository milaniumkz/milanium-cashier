# Зарплата2026 — поддерживаемая область

Schema20, API `/v1/companies/:companyId/payroll`. Внутренний расчёт обычной денежной зарплаты в KZT совершеннолетнего работника — резидента и гражданина Казахстана, у одного работодателя, без специальных льгот. Оклад в карточке сам по себе не создаёт начисление. Нужны подтверждённые кадровые сведения и заявления.

Источники и редакции: `docs/legal/register.json`, `observations.json`. Формулы: `server/src/payroll-calculation.js`. Документ сохраняет версию и снимок правил, входные сведения, базы, результат и состояние с начала года.

- МРП4325 тенге, МЗП85000 тенге; ОПВ10%, ОПВР3,5% с проверкой даты рождения, ВОСМС2%, ООСМС3%, СО5% с пределами баз.
- ИПН нарастающим итогом:10% до8500МРП/год,15% сверх. Вычет30МРП/месяц,360МРП/год требует заявления; перенос в пределах этого работодателя. Вычет другого работодателя автоматически не переносится.
- СН: общий режим ТОО6% объекта; ИП общего режима1МРП за работника; выбранный СНР без СН. Собственный налог ИП исключён. СО не вычитается из СН2026.
- СО округляется вверх до тенге по правилам №229; ОСМС — до тенге по правилу50тиын приказа №478. Округление остальных расчётов до тиына — явно подтверждаемая учётная политика модуля. Приёмка бухгалтером не проведена.

Пропущенные месяцы не считаются нулевыми. При старте в середине года требуется подтверждённый ввод фактических накопленных баз, вычетов и ИПН предыдущих месяцев этого работодателя. Он влияет на расчёт, не создаёт денег или проводок.

Предпросмотр выполняет сервер. Черновик, проведение, выплаты и правки проверяют разные полномочия. Изменение исходных данных после предпросмотра требует пересчёта. Выплата списывает реальный денежный счёт. Начисление относится к проекту или общим расходам; налоги остаются обязательствами фирмы.

Исправления доступны после оплаты и за закрытые периоды: сторнируются старые проводки, создаются новые, пересчитываются следующие месяцы сотрудника. Фактические выплаты сохраняются; переплата становится авансом, без автоматического возврата/удержания. Платёж можно исправить, отменить, восстановить с версией и историей. Связанная проводка редактируется через основание.

Отмена начисления пересчитывает следующие месяцы с нулевым начислением, но не увольняет сотрудника: СН ИП за числящегося работника может сохраняться. Правки отменённой записи применяются при восстановлении. Удаляется только черновик с сохранением аудита.

Не поддержаны иностранцы/нерезиденты, пенсионные и специальные освобождения, ОППВ, единый платёж, ГПХ, совместительство, отпускные/больничные, исполнительные удержания, валютная зарплата. Такие случаи отклоняются или явно исключены из подтверждаемой области. PDF — внутренний расчётный лист. Официальная200.00, отправка деклараций и платёжные поручения налогов не реализованы. Полное соответствие D-20 не подтверждено.

Проверки: границы и точные примеры формул; PostgreSQL права/версии/история/остатки/последующие месяцы; живой Flutter→HTTP→PostgreSQL; backup/restore начисления и выплаты.
