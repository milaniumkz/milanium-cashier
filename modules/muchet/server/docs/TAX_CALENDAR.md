# Календарь фирмы и подготовка

Schema21. `/v1/companies/:companyId/tax-calendar`, права `tax-calendar.read/write`. Задачи общие для фирмы и не фильтруются выбором проекта. Даты не создаются по непроверенной таблице налоговых сроков.

Пользователь задаёт название, дату, вид (налог/отчёт/подготовка/другое), основание и примечание и явно подтверждает, что проверил срок и его применимость. Это ручное подтверждение, не проверка источника сервером. Источник хранится как текст, сервер его не загружает. Доступны открытый/выполненный/отменённый статусы, исправление любой даты за любой период, версия, история с автором, поиск задач месяца по календарю и общий счётчик просроченных задач выбранного периода. Пагинация не уменьшает серверные итоги.

`/preparation/:month` хранит отметки проверки профиля, документов и контрольных соотношений. Для профиля нужны реквизиты фирмы и версия настроек; чужая или устаревшая версия отклоняется. Изменение настроек делает прежнее подтверждение профиля неактуальным. Для чтения подготовки требуется также `organization.read`; чтение задач само по себе не раскрывает профиль. Подготовка подтверждается пользователем, не автоматическим движком проверки официальных форм.

Задачи, их статусы и отметки не создают проводок, не списывают деньги, не отправляют отчёты и не подтверждают приём государственным органом. Автоматическая подстановка официальных сроков, переносы с учётом производственного календаря, внешние уведомления и официальный экспорт остаются открытой работой. API явно возвращает `automaticOfficialDeadlines:false`, `officialReportGenerated:false`.

Исправления доступны за закрытые периоды. Команды транзакционные и идемпотентные; история сохраняется. UI сохраняет неопределённую сетевую команду для повторения с прежним ключом. Backup/restore включает задачу с основанием и отметки подготовки. Сквозной сценарий проверяет сохранение, исправление, статус, историю, календарь и мобильную раскладку.
