# Правовые источники и границы проверки

Сетевой блок снят по указанию пользователя. Получены 12 официальных HTML-текстов с old.adilet.zan.kz; исходные полные копии оставлены вне Git. В register.json сохранены точные URL, заголовки, дата получения и SHA256. Для Налогового кодекса, закона о бухучёте и плана счетов прочитаны также официальные info-страницы с датами изменения.

**Получение текста не означает проверки всего документа.** Указанные в register.json selected_sections_researched относятся только к перечисленным статьям. observations.json содержит краткие результаты чтения, а не исполняемые утверждённые налоговые формулы. accepted/accountant и official_schema_verified не проставляются по техническим тестам.

Проверенные фрагменты текста: НК статьи286(16),503,723,726,848; закон о бухучёте ст.2; примечание о вступлении изменения плана счетов с01.01.2027; закон о бюджете ст.7. Это подтвердило необходимость разделять 600000МРП для допуска к СНР и135000МРП для освобождения соответствующего ИП от бухучёта, проверять местные ставки СНР, исключения НДС и период статуса поставщика. Нормы будущего периода нельзя выбирать по дате публикации.

Не утверждены продуктивные налоговые/зарплатные расчёты, сроки и официальный формат выгрузки, перечень всех применимых форм и стандарты финансовой отчётности для каждого профиля организации. Формулы старого Flutter-кода не становятся юридически проверенными благодаря успешным unit-тестам.
