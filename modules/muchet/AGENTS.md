# M-uchet

This is a sanitized Flutter/web frontend source import for a future independent backend, not a completed backend migration. Read README.md and BACKEND_MIGRATION.md before changes.

Do not restore the former cloud configuration, administrative scripts, account data, credentials or deployment workflows. Keep startup/authentication fail-closed until the new backend contracts and access controls are implemented and tested. Preserve useful domain models while replacing Firebase-specific adapters deliberately. Do not deploy or enable Actions without the user's separate direction.

The Dart package name remains uchet_s_d for import compatibility. Flutter/Dart were unavailable during preparation; do not claim build or tests passed without running them.
