# VK/OK через Chrome без приложений разработчика

Требование владельца: клиент сам входит в соцсеть и связывает свой открытый браузер
с MBusiness. Центральное приложение VK/OK и OAuth-токены соцсетей для этого режима
не нужны. Официальные API-интеграции сохраняются как отдельный необязательный режим.

## Установка и действия клиента

Публичная инструкция `/help/browser-publisher`, ZIP `/downloads/mbusiness-browser-extension.zip`.
Chrome120+, установка распакованного расширения через chrome://extensions.
Исходники — `browser-extension/`; сборка детерминирована:
`npm run package:browser-extension`. Ключи и данные клиента в пакет не включаются.

1. Владелец компании сохраняет ссылку на свою группу в «Публикации и рассылки».
   Допускается ссылка на пост: из неё определяется числовой ID группы.
2. Владелец выдаёт одноразовый код, пользователь вставляет его в расширение.
3. Пользователь входит в VK/OK на официальном сайте. Расширение не считывает
   пароли/cookie и не обходит CAPTCHA или подтверждение входа.
4. В группе настраиваются кнопка открытия нового поста (если она нужна), поле текста
   и кнопка публикации. Выбор кнопки публикации при настройке перехватывается.
5. Пользователь включает расширение, владелец создаёт задания с подтверждением прав
   на группу/материалы. Chrome и компьютер должны оставаться включёнными.

## Разграничение и безопасность

Код связи120бит, TTL10мин, одноразовый, на сервере только хэш. Токен устройства
отдельный, случайный256бит, на сервере только SHA256, доступ ограничен одной компанией.
Chrome storage.local доступен только trusted contexts; content script токен не получает.
Нет permissions cookies/history/debugger и `<all_urls>`. Вкладка и текст проверяются
перед публикацией; не допускаются поля входа, комментария и личного сообщения.

Сервер не называет сохранённую ссылку авторизацией соцсети. Сессия остаётся в браузере
пользователя. Статус «браузер на связи» означает связь с расширением, не App Review
или подтверждение доступа к каждому аккаунту.

Исключение из проверки Origin действует только на зарегистрированных маршрутах
`/browser-publisher/*` для Chrome extension origin. Эти маршруты не принимают
авторизацию cookie; нужен отдельный Bearer устройства (кроме одноразового pairing).
Ключ не позволяет управлять аккаунтом компании, деньгами, командой или настройками API.

## Устойчивая отправка

`schedule → preparing → sending → published | unknown`, до отправки возможен attention.

Сервер выдаёт одно задание одному устройству. После проверки/заполнения формы расширение
запрашивает ready: сервер записывает sending и возвращает одноразовое разрешение.
Расширение сохраняет этот этап локально до нажатия. Клик выполняется один раз.
Для результата published нужны новая прямая ссылка на пост нужной группы, совпадение
текста в карточке и очищенный редактор. Изображение прикрепляется только при однозначном
file input и подтверждённом отображении нового загруженного preview.

Перезапуск/разрыв после sending не вызывает повторную отправку. Неизвестный результат
блокирует следующие задания группы до ручной сверки владельцем. Просроченное preparing
переходит в attention; просроченное sending — в unknown. Отзыв устройства запрещает
новые команды и сохраняет неопределённый результат уже начатых отправок.

Лимиты:100 ожидающих заданий компании; не менее6 часов между постами в группе,
до3 за скользящие24ч; тот же текст в группе не чаще1 раза в7дней. При задержке браузера
контроль выполняется также по фактическому времени публикаций.

## Проверка и ограничения

Автоматические серверные проверки: одноразовость pairing, tenant isolation, CSRF,
хэширование токенов, разрешение sending, запрет повторов, lease expiry, отзыв,
проверка ссылки результата, права группы и нормализация URL.

Сквозной тест `npm run test:extension` устанавливает настоящий MV3 в Chromium,
связывает с сервером, настраивает скрытую форму, вставляет текст и PNG, нажимает один раз,
проверяет permalink и отсутствие повтора. Страница соцсети в этом тесте синтетическая.
Браузерный сценарий кабинета отдельно проверяет сохранение группы, pairing и расписание.

Реальные авторизованные аккаунты VK/OK не предоставлены. Работу с их текущим DOM нельзя
объявить проверенной по синтетическому тесту. Нужен первый контролируемый пост в своей
группе после установки и настройки. При неподдерживаемом редакторе/форме/изображении
расширение останавливается; UI не подменяет это успешной публикацией. Интерфейс сайта
может меняться, поэтому ручная перенастройка формы предусмотрена. Режим не обеспечивает
публикацию при выключенном компьютере и не гарантирует точное время после сна браузера.
