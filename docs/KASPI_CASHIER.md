# Подключение кассира Kaspi Pay к MBusiness

Полная пользовательская инструкция с диагностикой и отдельными шагами для
администратора: `/help/kaspi-cashier`. Она доступна без входа; ссылки есть
в «Интеграция → 1Kaspi → Кассир», документации API и админке.

## В Kaspi Pay

1. Руководитель, управляющий или бухгалтер открывает мобильное приложение Kaspi Pay.
2. Переходит: **Сервисы → Профиль компании → Сотрудники → Добавить**.
3. Выбирает роль **«Кассир»**, нужную точку продаж, вводит телефон и имя сотрудника.
4. Сотрудник получает SMS для установки приложения и регистрации.
5. Сотрудник завершает регистрацию в официальном Kaspi Pay на тот же номер;
   необходимые ИИН, банковский пароль и код быстрого доступа вводятся только там.
6. Проверяет доступ к нужной компании и точке продаж.

## В MBusiness

1. Войти в кабинет своей компании по логину/паролю MBusiness.
2. В «Мой аккаунт» указать точное название организации из Kaspi Pay
   в поле «Кабинет кассира в Kaspi».
3. Открыть **Интеграция → 1Kaspi → Кассир**.
4. Ввести телефон кассира `+7XXXXXXXXXX`, нажать «Получить SMS».
5. Ввести SMS-код только в форме подтверждения, нажать «Подключить кассира».
6. Дождаться статуса «Подключён» и успешной проверки организации.
7. Оплатить тариф; для API привязать постоянный исходящий IP и получить ключ.

Логин MBusiness, учётная запись кассира и API-ключ — отдельные данные доступа.
Одно добавление номера в Kaspi Pay без первого входа сотрудника недостаточно.
При истечении сессии повторяют подключение к исходной организации; неизвестные
платежи сначала сверяют, без создания повторного счёта.

Кассир клиентской компании принимает деньги покупателей. Кассир сервиса
для тарифов подключается отдельно администратором `/operator` → биллинг.
После сохранения точного названия организации выполнить SMS-вход, проверить
кассира и только затем включить приём оплаты тарифов. Пока кассир сервиса
не включён, покупка тарифа недоступна.
